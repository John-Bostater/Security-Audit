# Security Audit

CLI-based Python Application for performing a security audit on the user's system.

<br>



## What we look for

- All *Foreign IP Connections* running on the user's system,

- Local & reverse IP search information of *Foreign IP Connections*

- Task information on *Foreign IP Connections* (Windows OS only)

<br>



## Usage

Command<br>&nbsp;&nbsp;(yes... it's this simple!)

	python Check.py
